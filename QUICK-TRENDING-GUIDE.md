# Quick Trending Categories Guide

## For Admins

### Add a Trending Category (3 Steps)
1. Go to **Admin Panel** → **Trending Categories**
2. Click **"Add Category"**
3. Fill in:
   - Name (e.g., "Men's Jeans")
   - Upload cover image
   - Link URL (e.g., `/men`)
   - Display order (0 = first)
   - Check "Active"
4. Click **"Create Category"**

### Edit a Category
1. Click **Edit** button on category card
2. Change any field
3. Click **"Update Category"**

### Delete a Category
1. Click **Delete** button on category card
2. Confirm deletion

### Change Order
1. Edit the category
2. Change "Display Order" number
3. Lower numbers = appear first

### Hide/Show Category
1. Edit the category
2. Check/uncheck "Active"
3. Save

## Quick Tips

✅ **Image Size**: 800x600px (4:3 ratio)  
✅ **File Size**: Under 500KB  
✅ **Link Format**: `/men`, `/women`, `/sale`  
✅ **Display Order**: 0, 1, 2, 3... (0 is first)  
✅ **Active Categories**: Keep 4-8 for best look  

## Common Links

| Category | Link URL |
|----------|----------|
| Men's Jeans | `/men` |
| Women's Jeans | `/women` |
| Sale Items | `/sale` |
| Slim Fit (Men) | `/men?subcategory=slim-fit` |
| Skinny (Women) | `/women?subcategory=skinny` |

## Display Order Examples

```
Order 0: Men's Jeans (appears first)
Order 1: Women's Jeans
Order 2: Slim Fit
Order 3: Designer Denim
```

## Troubleshooting

**Not showing on homepage?**
- ✓ Check "Active" is checked
- ✓ Refresh homepage
- ✓ Verify image uploaded

**Wrong order?**
- ✓ Edit display order numbers
- ✓ Lower = first

**Image not loading?**
- ✓ Re-upload image
- ✓ Check file size < 500KB

Trending categories appear on the homepage in the "TRENDING CATEGORIES" section. Click any category to browse products.
